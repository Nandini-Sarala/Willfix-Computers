# Willfix & Computers — Laptop Repair Website

A clean, minimal, Apple-inspired website for **Willfix & Computers**, a solo walk-in laptop repair shop based in Toronto, Canada.

## Pages

| File | Description |
|------|-------------|
| `index.html` | Homepage — services, brands, how it works, visit info, reviews, FAQ |
| `about.html` | About page — owner story, why choose us, stats |
| `style.css` | Shared stylesheet (Apple-inspired design system) |
| `main.js` | Shared JavaScript — nav toggle, scroll reveal, footer year |
| `logo.jpeg` | Shop logo (used in nav on both pages) |

## Features

- Fully responsive (mobile, tablet, desktop)
- Sticky navigation with mobile hamburger menu
- Scroll-reveal animations on cards and sections
- Mobile sticky call bar (Call Now + Directions)
- FAQ accordion (open/close on click)
- Footer with Quick Links, Contact, and Social icons (Call, Instagram, Google Business)

## How to Run Locally
No build tools or installs needed. Just open the files directly:
```bash
# Option 1 — open directly in browser
open index.html

# Option 2 — use VS Code Live Server extension
# Right-click index.html → Open with Live Server
```

All 5 files must stay in the same folder for the site to work correctly.
